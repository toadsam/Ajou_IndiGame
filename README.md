# Ajou_IndiGame

아주대학교 인디게임 제작 프로젝트 저장소입니다. Unity 기반 3D 게임 프로토타입으로, 캐릭터/몬스터 에셋, 전투 연출, UI, 씬 구성을 실험합니다.

## 프로젝트 개요

`Ajou_IndiGame`은 인디게임 제작 과정을 기록하는 Unity 프로젝트입니다. 대규모 에셋과 여러 기능 실험이 포함되어 있으며, 게임 플레이 루프와 시각 연출을 함께 검증하는 데 초점을 둡니다.

## 주요 구현 영역

- Unity 씬 기반 게임 환경 구성
- 캐릭터와 몬스터 에셋 활용
- RPG/액션 게임용 UI와 아이콘 에셋 구성
- 이펙트와 사운드 스크립트 실험
- 카메라와 플레이어 제어 관련 스크립트 활용

## 기술 스택

- Unity `2022.3.23f1`
- C#
- Unity UI
- Unity Animator / Scene 시스템
- 3D 에셋 및 VFX 패키지

## 실행 방법

1. Unity Hub에서 `2022.3.23f1` 버전을 설치합니다.
2. 저장소 루트 폴더를 Unity 프로젝트로 엽니다.
3. Unity가 패키지와 에셋을 임포트할 때까지 기다립니다.
4. `Assets/Scenes` 아래의 시작 씬을 열고 Play 버튼으로 실행합니다.

## 개발 메모

이 저장소는 인디게임 제작을 위한 실험과 에셋 조합이 많이 포함되어 있습니다. 프로젝트를 포트폴리오용으로 정리하려면 시작 씬, 조작법, 게임 목표, 플레이 영상, 직접 구현한 스크립트 목록을 README에 추가하는 것이 좋습니다.
